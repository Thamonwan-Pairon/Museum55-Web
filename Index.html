HALL 03 // EVERYDAY LAB BUILT FOR EVERYDAY LIVING

ห้องแล็บความรู้เพื่อการใช้ชีวิตทุกวัน

เพราะความรู้จากอดีตไม่มีความหมายหากไม่ถูกแปลงเป็นสิ่งที่คนรุ่นใหม่ใช้ได้จริง นี่คือการ์ดความรู้ขนาด 1080×1350 px ที่คัดสรรมาเพื่อการทำงาน สุขภาพ และการคิดเชิงระบบ

PILLAR 01 // SMART WORK

"จัดระเบียบงานแบบ Flow Architecture เลียนแบบโครงข่ายคูคลองอยุธยาและพระนคร"

ลดการเกิดคอขวด (Bottleneck) ในการทำงานเป็นทีม ด้วยการกระจายงานออกเป็นทางน้ำหลากย่อย และกำหนดผู้รับผิดชอบตามระดับแรงดันของงาน เพื่อป้องกันระบบล่มสลายในชั่วโมงเร่งด่วน

PILLAR 02 // SUSTAINABLE LIVING

"Passive Cooling: อยู่ร่วมกับความร้อนในห้องคอนโดและบ้านด้วยหลักการเรือนไทย"

สร้างทางผ่านของลมข้ามห้อง (Cross Ventilation) และติดตั้งระแนงบังแดดในทิศตะวันตกเฉียงใต้ ช่วยลดอุณหภูมิสะสมภายในตัวอาคารได้จริง 2–4 องศาเซลเซียส ประหยัดค่าไฟแอร์ลง 25%

REF: GRM-1920-HIST
PILLAR 03 // CRITICAL THINKING

"Empirical Grounding: กรองข้อมูลในโซเชียลมีเดียด้วยระเบียบวิธีหว้ากอ"

ไม่เชื่อข้อมูลจากคลิปสั้นเพียงเพราะความรู้สึกหรือยอดวิว แต่ตรวจสอบว่ามีตัวแปรที่พิสูจน์ได้จริง (Verifiable Variables) หรือไม่ เพื่อสร้างภูมิคุ้มกันทางดิจิทัลให้แก่ตนเองและครอบครัว

REF: GRM-1872-SCI
HALL 04 // ABOUT & PHILOSOPHY THE 5-STAGE KNOWLEDGE JOURNEY

พันธกิจ 5 ขั้นตอนของภัณฑารักษ์จากอนาคต

"สำหรับคนวัย 22–40 ปีที่อยากเข้าใจโลกให้ลึกกว่าคลิปสั้น แต่ไม่อยากรู้สึกเหมือนนั่งเรียน" นี่คือเส้นทางที่เปลี่ยนข้อมูลประวัติศาสตร์ให้กลายเป็นปัญญาปฏิบัติ

STAGE 01 // EXCAVATE

ขุดค้น (Excavate)

คัดสรรความรู้จากประวัติศาสตร์ วิทยาศาสตร์ และภูมิปัญญา ระบุแหล่งที่มาและหลักฐานทุกชิ้นอย่างโปร่งใส 100%

STAGE 02 // DECODE

ถอดรหัส (Decode)

ถอดโครงสร้างข้อมูลเป็นโหนดและกราฟความรู้ (Knowledge Graph) ระบุความสัมพันธ์อย่างเป็นระบบ

STAGE 03 // RETELL

เล่าใหม่ (Retell)

สื่อสารผ่าน Visual Storytelling และอินเตอร์แอคทีฟดีไซน์ ให้เข้าใจง่ายและดูจบในเวลาเพียง 3-5 นาที

STAGE 04 // CONNECT

เชื่อมโยง (Connect)

เปิดชุดข้อมูลผ่าน Data Booming และ Interactive Graph ให้เห็นว่าความรู้ข้ามยุคสมัยเชื่อมโยงกันอย่างไร

STAGE 05 // APPLY

ประยุกต์ใช้ (Apply)

ปิดท้ายทุกนิทรรศการด้วยการ์ด Everyday Takeaway ที่ระบุวิธีนำไปใช้ในชีวิตและการทำงานจริงได้ทันที

ออกแบบเพื่อประชาชนคนรุ่นใหม่ 3 กลุ่ม

PERSONA 01 // AGE 22-27

Curious Starter

นักศึกษาจบใหม่และคนเพิ่งเริ่มทำงาน ต้องการเรื่องเล่ากระชับ สวยงาม และการ์ดความรู้สำหรับแชร์บน Social Media

PERSONA 02 // AGE 25-34

Creative Professional

นักออกแบบ ครีเอเตอร์ และนักพัฒนาซอฟต์แวร์ที่มองหาแรงบันดาลใจ ชุดข้อมูลที่ดาวน์โหลดได้ และ Interactive Graph เชิงลึก

PERSONA 03 // AGE 30-40

Lifelong Learner

คนทำงานและพ่อแม่รุ่นใหม่ที่ต้องการความน่าเชื่อถือ ตัวอักษรที่อ่านสบายตา และการนำความรู้สุขภาพและภูมิปัญญาไปดูแลครอบครัว
